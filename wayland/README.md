Wayland setup
=============

Look, ok. wayland is not it. not yet - While I managed to get it working smoothly after a while, it just still isn't smooth with the things I want from it, and a recent update just bricked my setup, making it impossible to share screens or anything. Keeping this here for posteriority/future experiments

## Requirements
`sway, waybar, way-displays, swayidle, swaylock`

`fuzzel` as a launch menu
`mako` as a notification manager
`grimshot` for screenshots
`alacritty` or another terminal emulator of choice
`polkit-gnome`/`polkit-gnome-authentication-agent` to fix issues with the default polkit, which is hella broken in wayland.
